## Before session 2

Each lab's last section runs a small AI agent built around your own code. That
needs a model key, set up once: read **[API_KEY_SETUP.md](API_KEY_SETUP.md)**
(ten minutes). No key? Every lab still runs; the agent cells will tell you so
and carry on.

## House rules

Nothing here can fail: every check prints, nothing raises, and an unfilled
blank says so politely. Run **Runtime → Run all** first, read the output, then
go back to the top and do the cells marked `YOUR TURN`.

Never paste an API key into a cell. Keys go in Colab's Secrets (the key icon
in the left sidebar) and nowhere else.
